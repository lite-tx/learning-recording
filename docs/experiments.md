# 设计实验记录

> 本文件用来记录可观察行为与我们从中得出的假设。不要把案例回放当作有控制条件的实验。

## 试验 001 — C++ vector 扩容与 reserve

- **测试目的**：在用户已经知道主要原理时，是否能避免不必要的基础复述，并发现具体知识偏差。
- **实际情况**：用户正确解释 `push_back` 可能因扩容使指针失效；在继续讨论 `reserve` 时，误记了它对容量与内存重新分配的影响。
- **观察**：从已知概念出发的示例说明有效；但主动追加问题可能超出用户当时的学习目标。
- **后续**：需要在新场景中比较「继续追问」与「按用户指示结束」的适用条件。

## 试验 002 — C++ 伪共享

- **测试目的**：遇到不熟悉的知识时，是否能从用户的硬件直觉继续推导，不一次引入大量术语。
- **实际情况**：用户推测问题来自硬件缓存；对「独立维护同一缓存行」的表述提出困惑；将额外开销联想到缓存换入换出与循环局部性。
- **观察**：应澄清缓存一致性下的行所有权争用，与一般内存访问局部性区别。
- **状态**：学习中途转向 GitHub 仓库建设，尚未将本次互动视作完整的教学效果测评。
