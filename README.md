# Learning & Recording

> 状态：**思想研究与案例验证阶段**。这里是我们共同设计学习插件的工作仓库，尚不是正式插件或已经验证的学习理论。

这个项目来源于一次很普通的经历：自己先提出一个未必完善的算法思路，再与 AI 共同分析、修改、验证，最后得到一个自己能理解的版本。这个过程本身值得保存。

## 想做什么

- **Learning（学习）**：用户与 AI 围绕一个问题共同探索。从用户已有的理解与设想出发，允许质疑、试错、直接讲解和必要的知识分支；AI 应帮助恢复主线，而不强加固定的教学步骤。
- **Recording（记录）**：从真实交流中保留思路的变化、理解发生偏差的位置、关键的推导桥梁，以及必要的结果与参考资料。记录应帮助未来重新理解，而非复述全部聊天。

这两个方向目前是**思想雏形**，不是已完成的 Skill 定义。

## 不急着做的事

不重新实现 ChatGPT / Codex 已有的推理、上下文、记忆、工具调用能力；不为每个知识点建立掌握度评分；不强制每次学习执行固定轮数或测试；不预设需要额外的 MCP 服务器或界面。

插件由用户**主动调用**，不自动介入所有对话。未来可以按需使用 Notion、Write Like Me 等现有能力；是否使用哪些工具、如何实现仍待共同设计。

## 协作约定

先讨论问题、保留不同意见，再修改思想底稿。区分用户的原始想法、共同形成的结论与外部研究的支持程度。外部研究用于检验、修正和启发，不作为必须照做的步骤表。

这份仓库不包含私人聊天全文和账户凭证。若以后需要链接个人 Notion 或私密会话，应通过适当权限与配置处理，不写入公开仓库。
