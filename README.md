# Learning & Recording

最近一直在和 ChatGPT 一起学算法，我慢慢发现，直接拿到一份很好的代码，有时候我反而不知道它为什么要这样写。比如之前做 LeetCode 3841，最开始看到优化后的代码，我看了很久还是不理解。后来我们从一个比较笨的 BFS 方案开始，先把第一版写出来，再一点点讨论树状数组和 LCA 怎么接进去。虽然绕了不少路，但最后整理出来的代码我反而能看明白了。

我就在想，这种方式应该也能用来学算法以外的东西，比如计算机原理、源码或者论文。所以想试着做一个插件，暂时叫 **Learning & Recording**。

## 现在的想法

**Learning**

我先说说自己是怎么想的，哪怕想法还不完整，甚至有错误，也可以先沿着它讨论。哪里有问题就一起找，缺什么知识就补一点。遇到值得深入的地方也可以临时开个分支，不过解决了眼前的问题之后，要记得回到原来在做的事情。

这个过程不需要固定成几个步骤。有时候我想自己推导，有时候又想直接听解释，具体怎么进行还是看当时的问题。

**Recording**

学完之后，我希望能把当时的思考过程记录下来。比如我一开始为什么会这样想，后来在哪里发现不对，又是怎么把它想明白的。

我觉得只记录最后的答案其实没什么意思，毕竟 AI 本来就能给出很好的答案。以后如果忘了，我更希望能看到自己当时是怎么推导出来的，然后顺着那条思路重新理解一遍。代码、资料这些当然也可以放进去，需要的时候再看就好。

## 目前做到哪里了

现在还在讨论和验证这个想法，正式的插件还没有做出来。

我们也在看其他人的学习方法，比如结对编程、认知学徒制等。我不准备看见一套成熟理论就直接照搬，还是想先看看它解决了什么问题，再和我们自己的经历比较。现在的想法以后很可能会变，但我也希望把这些变化留下来。

至于具体的实现，我准备尽量简单一些。ChatGPT 已经有的对话、记忆和工具能力就直接用；需要记笔记、参考文风时，也尽量调用已有的工具。
